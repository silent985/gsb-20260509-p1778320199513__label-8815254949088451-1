# 用户认证系统

一个基于 Vue 3、Vite、Pinia、Element Plus、Axios 和 TypeScript 构建的现代化安全用户认证系统。

## 项目简介

该项目是一个功能完整的用户认证系统，包含登录、注册和个人中心等核心功能，采用了现代化的前端技术栈和设计理念，注重用户体验和系统安全性。

## 技术栈

- **前端框架**：Vue 3 + TypeScript
- **构建工具**：Vite
- **状态管理**：Pinia
- **UI组件库**：Element Plus（按需引入）
- **网络请求**：Axios
- **样式**：现代CSS3（包含渐变、阴影、响应式设计等）

## 功能特性

### 登录功能
- 手机号码和密码登录
- 二次验证（短信验证码）
- 实时表单验证和错误提示
- 验证码发送倒计时功能

### 注册功能
- 多字段表单（手机号、邮箱、身份证号、地址）
- 实时表单验证
- 密码加密存储
- 身份证号格式验证

### 个人中心
- 用户信息展示（昵称、头像、账户状态）
- 个人信息详情（邮箱、身份证号、地址）
- 身份证号脱敏处理
- 登出功能
- 安全提示信息

### 设计特点
- **现代化UI**：采用渐变背景、半透明卡片、增强阴影等现代设计元素
- **响应式布局**：适配不同屏幕尺寸
- **流畅动画**：优化的过渡效果，确保动画流畅运行
- **视觉层次感**：通过阴影、圆角和间距创造清晰的视觉层次

## 安装步骤

### 1. 克隆项目

```bash
git clone <项目地址>
cd user-auth-system
```

### 2. 安装依赖

```bash
npm install
```

## 使用说明

### 开发模式

启动开发服务器，默认端口为5173：

```bash
npm run dev
```

访问 http://localhost:5173 即可查看应用。

### 构建生产版本

构建优化后的生产版本：

```bash
npm run build
```

构建产物将生成在 `dist` 目录中。

### 预览生产版本

预览生产构建的效果：

```bash
npm run preview
```

## 功能说明

### 登录流程
1. 输入手机号码和密码
2. 点击"发送验证码"，获取短信验证码
3. 输入验证码
4. 点击"登录"按钮
5. 登录成功后跳转到个人中心

### 注册流程
1. 填写所有必填信息（手机号、邮箱、身份证号、地址、密码）
2. 系统实时验证输入的信息格式
3. 点击"注册"按钮
4. 注册成功后自动跳转到登录页面

### 个人中心
1. 查看用户基本信息
2. 查看个人详细信息（身份证号已脱敏）
3. 点击"登出"按钮退出登录
